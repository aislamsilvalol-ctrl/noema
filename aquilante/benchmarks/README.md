# Benchmark

Generated by `scripts/benchmark_table.py` from `runs.jsonl`; every row is the latest recorded run of that model on that dataset. Reproduce with:

```bash
.venv/bin/aquilante benchmark --dataset configs/datasets/synthetic-benchmark.yaml --out benchmarks/runs --seeds 1 --epochs 12
.venv/bin/aquilante benchmark --dataset configs/datasets/synthetic-benchmark.yaml --out benchmarks/runs-3seeds --seeds 3 --epochs 12 --models mastery_heuristic,pfa,bkt,dkt,aquilante,aquilante-no_time,aquilante-no_forgetting
```

**Read this first.** Synthetic results validate the pipeline, not the models' value for real learners. The simulator is a Rasch-like process with mild log-time forgetting and per-learner rates (see `aquilante/simulation`); a model that wins here has learned that process, nothing more. The table is printed as measured.
