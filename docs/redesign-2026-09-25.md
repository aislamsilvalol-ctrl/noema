# NOEMA total redesign — audit and plan (2026-09-25)

Measured against `docs/brand-os.md` (the owner's reference set of 2026-09-17:
cobalt universe, bone, one ember, monumental image, one grotesk, radical
reduction). The brief of 2026-09-25 asks for the same world across every
surface, from the landing to the 404. This file records where the product
stands, what shipped, and what needs the owner.

## Where it stands

| Area | State |
|---|---|
| Colour system | Cobalt/bone/ink/ember tokens live; no raw orange/green/purple classes left outside admin after #192. |
| Landing | V5 on the scenes; editorial rhythm already follows the brief. |
| Landscapes | **Weakest brand asset.** Low-poly Blender scenes (cone trees, box house, broken road segments), green dominant in the lower half. They do not meet "real + dreamlike + editorial". |
| Mino | **Contradicts the brief.** Large glossy cartoon eyes, blush, drop head: the mascot the brief rejects (§9, §12). The app icon is Mino's face on an orange disc, outside the cobalt system. |

| Titles | Every client route has a localized document title (#193). |
| Inner screens | Older density: `text-xs` mono kickers, boxed heroes, hand-rolled inputs and chips. |

## Plan, in launch order

**P0/P1, code only (in progress)**
1. Shared Input, Textarea, Select and SegmentedControl; every hand-rolled one migrated.
2. Loading and empty states for notebooks, cards, settings, socratic, explain.
3. Density pass on the inner screens, following the /chat study rail.
4. Decide /socratic and /explain: hide for launch, or reach them from the lesson.

**Needs the owner**
5. Mino's art direction. The brief asks for a ceramic, restrained, silhouette-first character; the current model is the opposite. This is a character redesign in Blender or a generator, not a code change.
6. The landscapes. Regenerate the five scenes under one art direction. The Higgsfield account connected on 2026-09-25 is on the free plan with no credits.
7. The app icon, which follows whichever Mino ships.

**Cannot be done on this host**
- The screenshot loop the brief makes mandatory. There is no working browser here; every change is verified by tests, types, build and the live deploy's markup, and must be looked at on the deployed site.
