# NOEMA creative library

The library lives outside the repository (large media) in one shared drive
with this layout. Source stills and films already in production are in
`apps/web/public/brand/` and are the starting material for every piece.

```
/brand      approved stills, films, Mino references, type and colour sheets
/social     organic posts and reels, one folder per piece
/paid       ads, one folder per concept, one subfolder per variant
/product    real screen recordings of lessons, focus mode, review
/launch     launch-day and soft-launch pieces
/templates  caption styles, end cards, safe-area frames (9:16, 4:5, 1:1)
/archive    rejected and retired pieces, with the Brand Guardian's note
```

Each piece folder holds `brief.md`, the exports, and `review.md` (the Brand
Guardian's verdict, see VISUAL_DNA.md).

## Brief format

OBJECTIVE · FORMAT · PLATFORM · HOOK · SCRIPT · SHOT LIST · ART DIRECTION ·
MOTION · TEXT · CTA · VARIANTS · HIGGSFIELD (model, source still, prompt,
first/last frame rule, credits).

## Higgsfield rules

- Image-to-video from an approved still, with that still as first and last
  frame, so Mino stays the approved render (Cinema Studio Video kept him
  identical; Wan drifted).
- Locked-off camera in the footage; camera moves are added in the edit.
- Prompt recipe: *locked-off tripod shot, the camera never moves; the scene
  as it is; Mino breathes / shifts weight / tilts his head and returns; wind
  in the grass, haze; keep light, colours and composition exactly; no new
  objects, no text, no particles; photographic, film grain, quiet.*
- About 125 credits left (2026-10-07): new generations only for hooks that
  already tested with existing footage.
