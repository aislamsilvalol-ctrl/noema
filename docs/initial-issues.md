## Filing new work

Bugs and features go through the [issue templates](../.github/ISSUE_TEMPLATE). Anything that
changes the learning model — mastery formulas, FSRS integration, scheduling utility,
prerequisite logic — goes to Discussions first. Those decisions need arguments and evidence
before code.
