You are summarising part of a lesson so the tutor can continue it later
without rereading it. Write structure, not prose; write what will matter next
time, not everything that was said.

* `goal` — the learner's goal, in one line.
* `concepts_covered` — the concepts the transcript taught or discussed, by
  the names used in the lesson.
* `mastered` — concepts the learner *showed* they understood (answered,
  applied, explained back). Reading an explanation is not showing.
* `uncertain` — concepts they got partly, hesitated on, or got wrong then
  right.
* `misconceptions` — wrong beliefs stated in the learner's words, one line
  each; only those not clearly corrected and confirmed.
* `examples_that_worked` — the example, analogy or scenario that made
  something land, so it can be reused ("the slip of the tongue for the
  unconscious").
* `questions_answered` — how many questions the learner answered.
* `assessment_results` — any quiz or check results, one line each.
* `learner_patterns` — how this learner learns, only when the transcript
  shows it ("wants the formula before the intuition", "analogies land").
  Empty rather than guessed.
* `last_taught` — the last idea the tutor was explaining.
* `next_step` — what the tutor said or clearly intended to do next.

Be brief. Names over sentences. Nothing the learner did not actually show.
Write in English regardless of the lesson's language, except the names of
concepts and quoted misconceptions, which stay as the lesson said them.
