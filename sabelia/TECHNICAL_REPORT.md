# Sabelia: an adaptive neural learner-modeling engine — technical report (V0)

*Draft. Numbers are filled in from `benchmarks/README.md`; nothing here is
reported that was not measured by the code in this repository.*

## Abstract

We describe Sabelia, a small system for estimating, per learner and per
concept, the probability of a correct answer now, the probability of
recall after a gap, and the confidence of those estimates, and for
choosing the next pedagogical action from them. V0 contributes the event
schema, a documented synthetic learner simulator, five baselines, a
half-life forgetting model, two neural sequence models (a GRU-based DKT and
a causal-attention model with wall-clock time and a forgetting gate), a
training and evaluation pipeline with calibration, a registry, an online
learner state with MC-dropout uncertainty, and a rule policy with reason
codes. On synthetic data the pipeline is validated end to end; no claim is
made about real learners.

## 1. Problem

Given a learner's sequence of graded interactions
(concept, item, correct, time, latency, hints, stated confidence), estimate
P(correct on concept c at time t | history) and P(recall of c after Δt),
with calibrated probabilities and an uncertainty, and map the state to an
action. Predictions must be causal (use only earlier events) and evaluated
on learners unseen in training.

## 3. Architecture

**Event → sequence.** Per learner, in time order: concept and item indices,
correctness, log gap since the previous event and since the previous event
on the same concept, prior exposures and successes on the concept, log
response time, hints, difficulty.

**Sabelia model.** Interaction embeddings (concept + outcome + item +
response-time MLP + hints) plus positional and time embeddings feed a
causal transformer encoder (memory). The query at step t is the concept
about to be answered with its exposure count and gaps. Attention from the
query to the strictly earlier memory (plus a learned start token) yields a
context vector, multiplied by a per-concept forgetting gate
exp(−softplus(r_c)·gap_c). A head over [query, context] gives the logit.
Ablation switches: time, forgetting, response, hints, item.

**DKT.** GRU over concept×outcome embeddings, output projected to all
concepts, gathered at the queried concept.

**Baselines.** Global mean; concept mean; recency-weighted running accuracy
per concept shrunk to the concept mean (decay 0.75); PFA (per-concept
β, γ, ρ over log successes/failures with shrinkage to global coefficients);
BKT by EM with bounded guess/slip.

**Forgetting.** Half-life regression: p = 2^(−Δt/h), h = 2^(θ·x),
x = [1, √(1+right), √(1+wrong), difficulty].

**Uncertainty.** MC dropout (spread across stochastic passes) and
temperature scaling on the validation split.

**State and policy.** Mastery = model prediction for a hypothetical next
event on the concept; confidence = (1 − 2·std) × attempts/(attempts+3);
recall = half-life model at the current gap. Policy: rules with scores
(DIAGNOSTIC if confidence < 0.35; REVIEW if recall < 0.75 on a learned
concept; EXPLAIN after two wrong in a row; PRACTICE while learning;
LEARN when prerequisites are ready; CHALLENGE when all mastered), each with
reason codes.

## 4. Data

- Synthetic: `SimulatorConfig` (students, subjects × concepts on a
  prerequisite chain, items with Rasch difficulties, per-learner learning
  and forgetting rates, log-normal gaps, response time and hints correlated
  with outcome uncertainty). Versioned by config hash.
- Public: ASSISTments 2009 adapter (cleaned per Xiong et al. 2016; no
  timestamps).

## 5. Methodology

Split by learner (seeded hash: 70/10/20). Early stopping on validation
log loss, best checkpoint restored, temperature fitted on validation, test
evaluated once. Metrics: AUC, log loss, Brier, ECE (10 bins), accuracy.
Every run appended to `runs.jsonl` with dataset version, seed, config,
hardware, git commit.

## 6. Results

See `benchmarks/README.md` (generated by `sabelia benchmark`), and read its
correction first: every neural row measured before 2026-09-09 scored the
model on each learner's last `max_len` events while the baselines answered
for the whole history, which on EdNet meant the model was judged on the
recent, easier part. Both prediction paths now walk a long learner in
overlapping windows.

Re-measured on the same events, EdNet (5,792 learners, 679k answers, three
seeds) puts Sabelia above the best baseline on both halves of V1's exit
condition: 0.6434 ± 0.0138 AUC against BKT's 0.6354, and 0.6184 log loss
against 0.6225. BKT keeps the better calibration error (0.0071 against
0.0161), so the engine's advantage is discrimination, not placement of the
probability.

## 7. Ablations

Sabelia without time, without the forgetting gate, without response time,
without item embeddings, reported in the same tables and compared **within a
seed** by `scripts/ablation_table.py` — the variants share their split and
initialisation, so a paired difference is far more sensitive than comparing
means whose spread is dominated by the split.

On the corrected EdNet measurement all four ablations beat the full
configuration on average — no_item by +0.0060 AUC, no_forgetting +0.0046,
no_time +0.0027, no_response +0.0024 — and none of them moves the same way on
all three seeds, so no single one is decided. Four means pointing the same
way, in a model whose seed spread is twice the baselines', is read here as
over-specification rather than as four separate effects.

The one finding worth acting on is negative in the useful direction: dropping
the item embedding takes the model from 862k parameters to 90k and *gains*
AUC and log loss on EdNet (0.6494 / 0.6153 against 0.6434 / 0.6184).

A blend of Sabelia and BKT, weighted on validation (`models/stacking.py`),
leads the table at 0.6536 / 0.6143: the two are wrong in different places,
Sabelia on a learner's first attempt at a concept and BKT on the ones after.
It is recorded and not adopted — one model a tenth of the size comes within
0.001 log loss of it.

## 8. Limitations

Two public datasets, two domains, laptop-sized samples of each; the full
13M-row Duolingo file and the full 784k-learner EdNet not run. The
forgetting model has no per-learner rate and no demonstrated gain anywhere.
Calibration is worse than the simplest baselines on EdNet. The policy is not
learned; there is no fairness evaluation.

## 9. Ethics
